
# ⚛️ React & JavaScript Project Collection

This repository includes a collection of modern **React**, **JavaScript**, and **frontend web** projects designed for learning, showcasing features like component design, routing, Chrome extensions, REST APIs, state management, interactive UIs, and more.

---

## 📁 Project List

### 🟣 1. Bootstrap Website
Static responsive site built with **Bootstrap 5**, includes homepage, client section, and contact form.

### 🧩 2. ChromeExtension
Simple Chrome extension that toggles features between two states and includes a popup UI.

### 🔐 3. FacebookLoginPage
A Facebook-style login page clone with form validation and responsive layout.

### 📜 4. JavaScript
Contains various small vanilla JavaScript exercises and DOM manipulation demos.

### ⚛️ 5. React
A basic React setup for demonstrating components, props, and state.

### 📝 6. ReactProject
A React sample project showing practical component and hook usage.

### 🐍 7. SlitherGame
A browser-based JavaScript game inspired by **Slither.io** with keyboard controls.

### 🛠️ 8. backend
Simple backend setup using **Node.js** and **Express**, useful for full-stack apps.

### 👩‍🍳 9. cooking-ninja
A blog-style React app for recipes using React Router, custom hooks, and Firebase.

### 🖼️ 10. images
Image assets for frontend projects (used by multiple demo UIs).

### 🧠 11. magic-memory
A memory-matching game built with React, showcasing useState and useEffect hooks.

### 🌐 12. multipage-site
Static multipage website showing navigation, contact forms, and media embedding.

### 🚀 13. my-first-react-app
The very first React app scaffolding using `create-react-app`, used for learning JSX and state.

### 💰 14. my-money
A personal expense tracker built with **React Context API** and Firebase.

### 🔄 15. restfulapi
Frontend project that consumes a RESTful API (likely connected to backend folder).

### 🧘 16. the-dojo
A real-time project management dashboard app using **React Router** and Firebase.

### 🌍 17. tripago
A travel booking themed frontend app using styled components and routing.

### 🗺️ 18. use-mapbox-gl-js-with-react
Shows how to integrate **Mapbox GL JS** into a React component-based structure.

---

## 🛠 Technologies Covered

- React, JSX, Hooks (useState, useEffect, Context)
- React Router
- Firebase (Auth, Firestore)
- RESTful API Integration
- Chrome Extension APIs
- Bootstrap & CSS Modules
- JavaScript (ES6+)
- Mapbox GL JS
- Node.js & Express (for backend)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/oguzhansaritas/web-react-projects.git
   ```

2. Navigate to a project:
   ```bash
   cd ProjectFolder
   ```

3. Install dependencies (if applicable):
   ```bash
   npm install
   ```

4. Start development server:
   ```bash
   npm start
   ```

> Some projects are static HTML/JS/CSS, others require Node.js and npm to run.
